# Midnight calm

One colour means one thing. The slate background stays.

| Colour | Token | Means |
| --- | --- | --- |
| Sage `#8FC1A9` | `--accent` | Do this: primary buttons and the current item |
| Gold `#D4AF37` | `--earned` | Earned: a verified Solved alone, the streak, a milestone reached, the owl logo |
| Amber `#D9B36C` | `--attention` | Needs attention: must-do-first and real warnings |
| Slate-blue `#8FA8CC` | `--help` | Needed help. Neutral, not a failure |
| Grey | `--done` | Finished, with a check mark |

Gold is never used on a button. Easy, Medium and Hard are a small dot plus a letter. Easy and Medium use LeetCode's green `#00B8A3` and amber `#FFC01E`. Hard uses the same red family as LeetCode's `#FF375F`, lightened to `#FF5C7A` so the small letter stays WCAG AA on a card.

The silk texture is not drawn for the everyday screens. It appears on the Plan Mode welcome and on a milestone whose date is today. A dark scrim sits over it so the words stay on slate.

`--gold` is renamed to `--accent`. The old name was sage, which made gold look like a button colour.
