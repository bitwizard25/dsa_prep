# Think-first v2

The gate asks you to derive the approach: understand the example, name a speed budget, describe a brute force, spot the waste, pick the fix. The pattern is the one that row leads to. It is not a guess from a list of 14.

A Plan Mode plan is owned by the Hub. The practice plan menu is read-only and offers Change in Plan Mode. Practice values, valid or not, do not write that goal. A plan that was created in the practice app still uses the guarded copy from before.

Records with `think.version` 2 use the new solved-alone rule. Older records stay on the old rule and are labelled v1. They are not re-scored.

The 10 minute timer only reveals a Stuck? panel. Skip is still there, and it is stored as skipped.
